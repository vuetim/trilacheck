# Trilacheck hero image metadata

Use these values in the WordPress Media Library. Hero images are decorative in the slider template, so the rendered `<img>` intentionally has an empty `alt` attribute; the slide heading already describes the destination. The Media Library alt text remains useful if an image is reused elsewhere.
